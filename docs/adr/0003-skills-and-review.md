# ADR 0003: Adapt KB skills through reviewed MDB operations

Accepted: preserve KB's 22 skill sources for provenance and expose adapted MDB skill instructions alongside 12 native agent-memory skills. Runtime dispatch uses the SDK, never upstream direct filesystem mutation scripts.

Copying upstream instructions verbatim as executable agent authority would bypass immutability, scopes and network consent. Instead, semantic functions create evidence-backed review proposals; missing media/network/model adapters report unavailable. A deterministic fixture demonstrates the pipeline without claiming real synthesis. Host-assigned identity and explicit promotion remain separate from imported text and model output.
