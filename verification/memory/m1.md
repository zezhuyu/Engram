## Implemented and tested
- **Event envelope** with strict validation (`MemoryEvent`), owner-written **registrations** (identity, workspace/collection, allowed types, exclusions, consent), and a **durable bounded spool** with an overflow policy that evicts/drops low-value events first and counts drops. Dedup `(host,eventId)` rides on the journal-enforced idempotency key, so it survives restarts.
- **Hook recorder** (`mdb memory capture`): silent, fail-open, never opens the vault or a model; tested with a missing vault, bad registration, malformed payloads, a held writer lock, and a killed drain.
- **Redaction before queueing** (keys, tokens, JWTs, private keys, `password=` values); hidden-reasoning fields never read; exclusion patterns drop events before they are queued.
- **Forgery resistance:** nine forged-event cases (principal, workspace, collection, registration, type, timestamp, schema, host, extra field) rejected; ACL revocation fails closed; instruction-like prompt text stays data.
- **Adapters** for Claude Code and Codex: consented, dry-run, idempotent, merge-only, timestamped backup, exact restore on uninstall, refuses unparseable settings, honest coverage reporting.
- **Recall:** `recent`, `timeline`, `time_range`, `search` (grep/regex/keyword/links/auto), `get`, `insight search`, `capabilities`, through SDK, CLI and MCP (identity bound by the host, forged identities rejected). Cursors, token budgets, progressive disclosure, timezone semantics, SQLite parity, stale/corrupt index behavior. `semantic`/`hybrid` → `CAPABILITY_UNAVAILABLE`.
- Passive-capture jobs (session-end retrospective, partial handoff for abandoned sessions) are queued in the **owner's** worker queue (fix found while testing: they were previously invisible to `mdb intelligence run`).

## Gate evidence (real host)

Real Claude Code 2.1.285, hooks installed by our adapter into a *temporary* `--settings` file: the host finished its task; user prompt, tool outcome and session end were captured; a different principal retrieved the record; a stranger got nothing; with the vault directory destroyed and hooks still installed the host still finished and the vault was not recreated.
